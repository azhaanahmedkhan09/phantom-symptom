PHANTOM SYMPTOM - ONE CLICK DEMO

1. Make sure Python is installed.
2. Double-click START_PHANTOM.bat.
3. A browser opens automatically at http://127.0.0.1:8000.
4. Upload a crop/leaf image and enter symptoms/environment values.
5. Click Analyze My Crop.
6. On the first analysis, paste your Gemini API key when asked.

The key is kept only in the browser session and sent to the local backend for the Gemini request. Do not publish this demo with a real API key embedded in source code.

The launcher installs the three required Python packages automatically and starts the local FastAPI server. Keep the black terminal window open while using the website.
